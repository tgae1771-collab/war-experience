# 휴대폰 이야기 — 최소 시작 틀

AI 에이전트에게 넘겨 새로운 휴대폰형 인터랙티브 서비스를 만드는 출발점입니다.
새로 작성한 독립 샘플이며 기존 운영 게임의 소스·스토리·미디어·계정 정보를 포함하지 않습니다.

## 실행

1. 압축을 풀고 이 파일이 있는 폴더에서 터미널을 엽니다.
2. Node.js 20 이상이 설치되어 있다면 `node serve.cjs`를 실행합니다. 별도 패키지 설치는 없습니다.
3. `http://127.0.0.1:4173`을 엽니다. 종료는 터미널에서 Ctrl+C입니다.

다른 방법: Python 3이 있다면 `python -m http.server 4173 --bind 127.0.0.1`로 실행해도 됩니다.
ES 모듈을 사용하므로 index.html 더블클릭 대신 로컬 HTTP 서버로 여세요.
이 서버는 로컬 미리보기 용도입니다.

## 들어 있는 기능

- 빈 휴대폰 프레임과 홈, 앱 열기·닫기
- 앱 등록 API와 앱별 JSON 상태 저장(localStorage)
- 메시지 한 개 → 선택지 두 개 → 서로 다른 결과의 가상 예제
- 새로고침 후 진행 재개, 예제의 다시 시작

홈에 보이는 앱은 메시지 예제 하나입니다. 상단 시계는 화면을 열 때 갱신합니다.
저장은 같은 브라우저·같은 origin에서 유지됩니다. 저장소가 차단되면 현재 탭 메모리에서만 진행합니다.
개인정보나 비밀번호를 저장하는 용도로 사용하지 마세요.

## 파일

| 파일 | 역할 |
|---|---|
| `index.html` | 휴대폰 껍데기와 진입점 |
| `style.css` | 프레임, 홈, 메시지 기본 모양 |
| `src/core.js` | 앱 등록·화면 전환·앱별 상태 저장 |
| `src/story.js` | 가상 메시지와 선택지·결과 데이터 |
| `src/apps.js` | 메시지 예제 앱 등록·렌더링·선택 처리 |
| `serve.cjs` | 의존성 없는 로컬 미리보기 서버 |
| `AGENTS.md` | AI 에이전트 인계 지침 |

다국어·통화·SNS·실제 OS 연동·계정·AI API·통계·서버 저장·빌드·배포는 포함하지 않습니다.
데모의 모든 인물·대화는 가상입니다. 화면의 앱은 실제 메시지를 보내지 않습니다.
